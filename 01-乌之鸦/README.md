## 简介

二十四岁的林砚在一趟轨道列车上救下了一个人。事后他才知道，被救的是游戏集团的负责人，袭击者则来自一支解散多年的开发团队。他们的游戏没能发行，相似的作品却在别人的平台上卖得很好。这件事，他们追了六年。

林砚想把事情弄清楚。他与调查记者许澄找到散落各地的十九名成员，翻开发记录，核合同，请律师，重新起诉。法院确认了合作中的违约，却没有支持他们最在意的请求。事情有了判决，失去的几年仍然无处讨还。

后来，一场秘密实验让林砚获得了操纵特殊介质的能力。他戴上鸟喙面具，以“乌鸦”的身份出现在公众面前。被搁置的工伤记录重新有人追问，停工的住宅楼终于亮了灯。许多人开始等他出现，他也越来越难对下一件事袖手旁观。

但有一次，他赶在所有人之前解决了眼前的问题，随后才发现，自己也打断了另一群人追查已久的线索。

《乌之鸦》的故事发生在近未来。跨国司法、警务与监管逐渐汇入被称为“地联”的公共体系。林砚曾相信这套体系能把事情处理好；成为乌鸦以后，他开始亲自决定什么事不能再等。
