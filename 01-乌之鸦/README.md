## 简介

近未来，实时翻译消除了语言壁垒，资本、数据与服务开始以前所未有的速度跨越国界。为了处理任何单一国家都无力追索的问题，一套共享司法、警务与监管资源的全球政治体系逐渐形成，人们称它为“地联”。

二十四岁的林砚出生于地联上层家庭，习惯认真看待具体的人和问题。他相信问题应当被调查，侵权应当被起诉，制度即使缓慢，也至少能够纠错。一次轨道列车上的暴力事件，让他接触到已经维权六年的原创游戏团队“白狐”。林砚与调查记者许澄替他们重新搜集证据、承担诉讼成本，把正规道路完整走到最后，却得到一个法律上可能正确、现实中仍然不公的答案。

此后，林砚获得了操纵一种特殊介质的能力，并以“乌鸦”之名介入那些制度来不及或无法解决的不公。乌鸦珍视生命，始终克制力量的使用，也会主动保护行动现场的每一个人。然而，当个人善意逐渐成为不受复核的公共权力，林砚和他身边的人都必须决定，这条道路究竟应该在哪里停下。
