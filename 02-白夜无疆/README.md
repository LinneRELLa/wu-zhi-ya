## 简介

阿岚湾停火后，陆昭没能走出隧道。林砚收到坐标就赶了过去，仍迟了十几分钟。他有足够的力量，也足够快，却不知道朋友正在哪里等着救援。

此后，他委托两家公司设计计算架构与人工智能模型，建立了“白夜”。这个系统能够持续观察现实，推演不同选择的后果。它先为城市规划和公共医疗提供建议，随后进入诊所、企业、学校，也进入林砚与许澄的生活。

白夜的建议一次次得到验证。疾病和事故减少，生活宽裕起来，人们逐渐习惯在决定之前问它一句。直到一些研究者发现，自己花了数年才完成的工作，白夜早就知道怎样做；连何时提示、容许他们失败多久，也经过了计算。

有人开始申请一片共同退出白夜的区域。他们想试着自己生活，医院、学校、工作和家人都要一起考虑。
